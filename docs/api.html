API reference

Every factory takes the same data object. This page covers the four keys, event handling, all exported tag functions and the package entry points.

Source of truth: lib/core and lib/types

Overview

The package creates DOM elements from function calls. element(tag, data) is the generic HTML factory. The SVG and MathML entry points each export the same function under the name element, and every tag also has its own named function.

element<T extends keyof HTMLElementTagNameMap>(
  tag: T,
  data?: ElementData<T>,
): HTMLElementTagNameMap[T]

A tag function has the same shape with the tag fixed. For example, div(data?: ElementData<'div'>) returns HTMLDivElement. 

import { div } from 'fiore';

const card = div({ children: 'Hello' });

document.body.appendChild(card);
Return value. The factory returns the native element. There is no wrapper object to unwrap before appending it.

Install and imports

npm install -D fiore

The package is ESM. Each entry point maps to a module in lib/, and the package has no runtime dependencies.

svg.circle({ attributes: { r: '8' } });

element()

element(tag, data) creates an HTML element with document.createElement, applies the data object in a fixed order and returns the node. The data argument is optional.

  1. props is assigned first.
  2. attributes is applied with setAttribute.
  3. children is passed to replaceChildren.
  4. event listeners are attached last.
import { element } from 'fiore';

const panel = element('section', {
  props: { className: 'panel' },
  attributes: { 'aria-label': 'Details' },
  children: ['Plain text', element('span', { children: 'and a node' })],
  event: { click: () => console.log('clicked') },
});

The data object

Key Type Applied by
props ElementProps<T> Object.assign
attributes HTMLElementsAttributesMap[T] setAttribute
children Children replaceChildren
event ElementEventData<T> addEventListener

Every key is optional and accepts undefined or null.

props

props uses JavaScript property names. It is typed as ElementProps<T>, which keeps the writable properties of the element and makes them recursively partial. 

div({
  props: {
    className: 'card',
    textContent: 'Hello',
    style: {
      padding: '16px',
      background: 'white',
    },
  },
});

Nested objects such as style are collected first, then assigned to the matching element property. Object keys are assigned with Object.assign.

Read-only DOM properties are excluded by the type. To set a read-only value, use a writable property or an attribute instead.

Source: lib/core/base.js:19

attributes

attributes uses HTML attribute names and calls setAttribute(key, value) for each entry. Attribute values must be truthy: an empty string or false is skipped. 

input({
  attributes: {
    type: 'email',
    required: 'true',
    'aria-label': 'Email address',
    class: 'field',
  },
});
Boolean attributes. Pass a truthy value such as 'true'. Passing '' or false skips the attribute entirely.

Property names and attribute names differ for some elements. Use the attribute column with attributes and the property column with props.

Attribute Property Example
class className attributes: { class: 'card' }
for htmlFor props: { htmlFor: 'email' }
tabindex tabIndex props: { tabIndex: 0 }
aria-label ariaLabel attributes: { 'aria-label': 'Close' }

Per-tag attribute types come from lib/types/attributes.d.ts. Global HTML attributes, ARIA, RDFa and tag-specific attributes are included.

Source: lib/core/base.js:44

children

children accepts a string, an element or an array of both. The value is passed to replaceChildren, so arrays are spread into the call.

type Children = string | Element | (Element | string)[]
div({
  children: [
    'Status:',
    span({ children: 'ready' }),
  ],
});

Numbers and text nodes are not part of the type. Convert a number to a string when it should appear as text.

Source: lib/core/base.js:62

event

event maps native event names to a handler. The key is the event name used by addEventListener, such as click, not the property name onclick.

A value can be a function or an object with handler and options:

button({
  children: 'Save',
  event: {
    click: (event) => console.log(event.currentTarget),
    keydown: {
      handler: onKeyDown,
      options: { once: true, capture: false },
    },
  },
});

The handler is typed as (this: T, ev: E[K]) => unknown, where T is the element and E[K] is the event type. The options value is the same boolean | AddEventListenerOptions that addEventListener accepts.

Listener order. Listeners are attached after props, attributes and children. An entry with no handler is skipped.
