Get started

HTML, SVG and MathML elements in JavaScript.

One function per tag. Props, attributes, children and event listeners go in. A native DOM node comes out.

$ npm install -D fiorejs
Read the documentation GitHub

No runtime dependencies. TypeScript declarations included.

One job: build the element.

The call creates a node, applies the data you passed and returns it. Every behaviour below links to the line that implements it.

Native nodes, no wrapper

element() calls document.createElement(tag) and returns that node. There is no wrapper object between your code and the DOM.

One call, four inputs.

The same shape works for div, circle or mi. Every key is optional.

  1. props

    JavaScript properties, including nested objects such as style.

  2. attributes

    Values passed to setAttribute. Falsy values are skipped.

  3. children

    A node, a string or an array, passed to replaceChildren.

  4. event

    Listeners are attached last, as a handler or as { handler, options }.

panel.js 
import { element } from 'fiorejs';

const panel = element('section', {
  props: { className: 'panel' },
  attributes: { 'aria-label': 'Details' },
  children: [
    element('h2', { children: 'Details' }),
    element('p', { children: 'Built with functions.' }),
  ],
  event: {
    click: { handler: onClick, options: { once: true } },
  },
});

Add it to your project.

Install from npm, import a tag and append the node. The package is ESM and has no runtime dependencies.

  1. Install the package.
  2. Import a tag function or element.
  3. Append the returned node.
